# منظومة ماي أودت – My Audit Platform
## المنصة السحابية المتقدمة لإدارة عمليات المراجعة الخارجية الشاملة وفق المعايير الدولية (ISA / SOCPA / ISQM)

تُمثل **منظومة ماي أودت (My Audit)** تطبيقاً برمجياً متكاملاً لإدارة دورة المراجعة الخارجية من قبول العميل حتى إصدار تقرير المراجع المستقل، مصممة خصيصاً لمكاتب المراجعة في المملكة العربية السعودية والشرق الأوسط، مستندة إلى مبدأ:
> **"لا يوجد خطر بدون إجراء، ولا إجراء بدون دليل، ولا نتيجة بدون تدقيق"**.

---

### المرجعيات والمعايير المهنية المطبقة برمجياً:
1. **معايير المراجعة الدولية (ISA) المعتمدة من الهيئة السعودية للمراجعين والمحاسبين (SOCPA)**:
   - **ISA 210**: شروط الارتباط وقبول العميل واستمراره.
   - **ISA 220 (المُحدّث)**: إدارة الجودة على مستوى الارتباط ومسؤولية الشريك.
   - **ISA 230**: التوثيق وأوراق العمل الإلكترونية الكاملة وتتبع طوابع التعديل.
   - **ISA 315 (المُراجع 2019)**: تحديد وتقييم مخاطر التحريف الجوهري (Inherent & Control Risks -> RMM).
   - **ISA 320**: حساب الأهمية النسبية العامة (Overall) والتنفيذية (Performance) وعتبة التافه (Clearly Trivial).
   - **ISA 330**: الاستجابة للمخاطر وتصميم البرامج والإجراءات الرقابية والتفصيلية.
   - **ISA 450**: تقييم التحريفات غير المصححة وتأثيرها على رأي المراجع.
   - **ISA 505**: إدارة طلبات ومطابقات المصادقات الخارجية مباشرة مع البنوك والعملاء والموردين.
   - **ISA 530**: محرك العينات الإحصائية (Monetary Unit Sampling - MUS والمعاينة المنتظمة).
   - **ISA 700 / 701**: صياغة وإصدار تقرير مراجع الحسابات المستقل وأمور المراجعة الرئيسية (KAMs).
2. **معايير إدارة الجودة الدولية (ISQM 1 & ISQM 2)**:
   - نظام رقابة الجودة وبوابات الجودة الصارمة (Gate System).
   - الفحص المستقل لجودة الارتباط (EQCR - Engagement Quality Control Review).
3. **نظام حماية البيانات الشخصية السعودي (PDPL)**:
   - سجل تدقيق رقمي غير قابل للتعديل (Immutable Audit Trail) وتشفير البيانات.

### هيكلية النظام (Architecture & Code Structure):
```
my_audit/
├── my_audit/
│   ├── database.py             # مخطط قاعدة البيانات SQLite وعلاقات الجداول وسجل التدقيق
│   ├── models.py               # نماذج التحقق وقواعد Pydantic
│   ├── engines/                # محركات الحسابات وقواعد التدقيق:
│   │   ├── trial_balance_engine.py  # استيراد الميزان، كشف الشذوذ، النسب المالية والتحليل الأفقي/الرأسي
│   │   ├── mapping_engine.py        # محرك التصنيف الذكي للحسابات إلى IFRS / SOCPA
│   │   ├── materiality_engine.py    # محرك الأهمية النسبية الثلاثي وفق ISA 320
│   │   ├── risk_engine.py           # مصفوفة تقييم المخاطر وتحديد RMM واقتراحات المخاطر الآلية
│   │   ├── sampling_engine.py       # محرك العينات الإحصائية النقدية MUS والمعاينة المنتظمة
│   │   └── quality_gates.py         # بوابات الجودة وضوابط الانتقال بين المراحل
│   ├── services/
│   │   ├── audit_service.py         # منطق الأعمال المتكامل لدورة المراجعة
│   │   └── report_generator.py      # توليد جداول الإسناد (Lead Schedules) والقوائم والتقرير المستقل
│   ├── api/
│   │   └── app.py                  # خادم REST API مبني بواسطة FastAPI
│   ├── web/
│   │   └── templates/
│   │       └── index.html          # واجهة تفاعلية كاملة باللغة العربية (RTL)
│   ├── seed_data.py            # بيانات نموذجية لشركة سعودية مكتملة الدورة
│   └── cli.py                  # واجهة سطر الأوامر التفاعلية
├── tests/
│   └── test_audit_system.py    # اختبارات آلية شاملة لجميع المحركات والخدمات
├── run.py                      # نقطة الدخول الرئيسية للتشغيل السريع
├── requirements.txt            # متطلبات التشغيل
└── README.md                   # دليل التوثيق
```

### طرق التشغيل:

#### 1. تشغيل المحاكاة الشاملة لدورة المراجعة عبر الطرفية (CLI Demo):
```bash
python3 run.py --demo
```
يقوم هذا الأمر بتشغيل دورة مراجعة كاملة من قبول العميل، استيراد ميزان المراجعة، التحقق من التوازن، احتساب الأهمية النسبية، تقييم المخاطر، تنفيذ برامج المراجعة وأوراق العمل، فحص المصادقات، تقييم التحريفات، اجتياز بوابات الجودة، وإصدار التقرير النهائي.

#### 2. تشغيل واجهة الويب ولوحة التحكم (Web Dashboard & API):
```bash
python3 run.py --serve --port 8000
```
ثم فتح المتصفح على العنوان: `http://localhost:8000` للوصول إلى لوحة التحكم التفاعلية، وتصفح التوثيق التلقائي لـ Swagger API عبر: `http://localhost:8000/docs`.

#### 3. تشغيل حزمة الاختبارات الآلية (Test Suite):
```bash
python3 tests/test_audit_system.py
```
